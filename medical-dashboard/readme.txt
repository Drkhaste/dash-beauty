داشبورد وردپرس را با تم سبز پزشکی مدرن، راست‌چین و بدون نیاز به هیچ CDN یا API خارجی زیبا می‌کند.

== Description ==

Medical Dashboard Pro یک پلاگین سبک و قدرتمند است که ظاهر داشبورد وردپرس شما را با:

✅ تم سبز پزشکی زیبا
✅ پشتیبانی کامل از راست‌چین (RTL) و فارسی
✅ بدون نیاز به هیچ CDN، API یا فونت خارجی
✅ Border-radius روی تمام المان‌ها
✅ دکمه‌های مدرن با گرادیانت و سایه
✅ فیلدهای ورودی زیبا با افکت فوکوس
✅ صفحه ورود کاملاً ری‌دیزاین شده
✅ منوی کناری مدرن
✅ جداول زیبا
✅ نوتیفیکیشن‌های رنگی

== Installation ==

1. پوشه `medical-dashboard` را در `/wp-content/plugins/` آپلود کنید
2. از طریق منوی "افزونه‌ها" در وردپرس، پلاگین را فعال کنید
3. لذت ببرید! هیچ تنظیمات اضافه‌ای نیاز نیست

== Frequently Asked Questions ==
